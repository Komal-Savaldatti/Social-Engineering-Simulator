# Social Engineering Simulator

A Flask-based cybersecurity awareness project developed to demonstrate social engineering and phishing awareness techniques in a safe educational environment.

---

## 📌 Project Overview

This project simulates a phishing-style login page to help users understand:

- Social engineering attacks
- Phishing awareness
- Suspicious websites
- Password safety
- Cybersecurity best practices

This project is created only for educational and awareness purposes.

---

## 🚀 Features

- Flask web application
- Simulated login page
- Email awareness simulation
- User activity logging
- Cybersecurity awareness dashboard
- Logs viewer
- Simple modern UI

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- SMTP Email

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/social-engineering-simulator.git
```

### Install Flask

```bash
pip install flask
```

### Run Project

```bash
python app.py
```

Open browser:

```bash
http://127.0.0.1:5000
```
